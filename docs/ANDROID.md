# Home Master Android APK

В репозитории выпускается **один пользовательский APK — Home Master**. Отдельного APK ProntoF нет.

## Сборка

GitHub Actions запускает сборку debug APK при изменениях Android-клиента или веб-интерфейса Home Master в ветке `main`, а также вручную:

- Workflow: `.github/workflows/android-apk.yml`
- Artifact: `HomeMaster-debug-APK`
- Файл внутри артефакта: `app-debug.apk`
- Package ID: `org.prontofix.app.debug` для debug-сборки.

## Подключение к серверу

При первом запуске Android-клиент попросит адрес сервера Home Master. Укажите, например:

```
http://IP-АДРЕС-NAS:30801
```

Можно использовать актуальный LAN-адрес NAS либо его Tailscale IP, если телефон подключён к тому же tailnet. Не используйте старый адрес или порт без проверки.

Адрес можно изменить через меню приложения. Интерфейс загружается по адресу `/app/`.

## Возможности Android-оболочки

- выбор файлов через системный Android file picker;
- сохранение файлов через системное окно «Сохранить как»;
- камера и геолокация с запросом разрешений;
- фоновая очередь отправки заказов;
- обновление APK с проверкой SHA-256 и подтверждением Android.

APK является оболочкой Home Master; рабочая логика и обработка видео находятся на сервере.
