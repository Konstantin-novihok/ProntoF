# ProntoF Android (первая тестовая сборка)

Android-приложение — лёгкая WebView-оболочка для самостоятельного сервера ProntoF.

## Сборка

GitHub Actions автоматически собирает debug APK при каждом push в main:
- Workflow: `.github/workflows/android-apk.yml`
- Artifact: `ProntoF-debug-apk`
- Файл: `app-debug.apk`

APK не содержит адрес сервера, введённый адрес сохраняется локально на телефоне. При первом запуске приложение попросит URL сервера; адрес можно изменить через меню «Адрес сервера».

## Подключение

Укажите доступный с телефона адрес, например `http://100.87.176.13:30810/`, если этот Tailscale IP NAS действительно актуален и телефон подключён к тому же tailnet. В противном случае используйте LAN IP или актуальный Tailscale IP.

На этой тестовой стадии разрешён HTTP для локального/Tailscale тестирования. Для публичного использования необходимо настроить HTTPS и отключить cleartext traffic.

## Ограничения первой версии

- WebView отображает веб-интерфейс сервера; основная функциональность зависит от доступности сервера.
- APK пока debug, не подписан production-ключом.
- Не реализованы фоновые загрузки Android, push-уведомления и отдельные нативные экраны.
- Загрузка файлов зависит от поддержки HTML file picker в WebView; отдельное тестирование на телефоне обязательно.
