# ProntoF — внутренний модуль обработки видео для Home Master

ProntoF работает как отдельный внутренний Docker-сервис обработки видео. Пользователь не открывает отдельное приложение и не создаёт в нём учётную запись: добавление видео и просмотр результата выполняются из Home Master в процессе работы с заказом.

## Интеграция

- Home Master остаётся единственным пользовательским приложением, интерфейсом, системой пользователей и заказов.
- Home Master передаёт видео в этот сервис частями по внутреннему API.
- Связь с заказом Home Master хранится как внешний номер заказа; отдельная видеотека для пользователя не используется.
- Внутренние маршруты требуют общий секрет `INTERNAL_API_KEY` в заголовке `X-ProntoF-Internal-Key`.
- Не публикуйте внутренний ключ и не добавляйте его в GitHub.
- Веб-интерфейс ProntoF не запускается: контейнер предоставляет только API и фоновый CPU worker.

## Обработка

- Chunked upload: части до 32 MiB, программный предел по умолчанию 500 GB, проверка свободного места.
- Faster-Whisper CPU int8.
- Argos Translate при наличии установленной языковой пары.
- Очередь с одним CPU worker, текст распознавания и перевода.
- Поддерживаются языки: украинский, русский, немецкий, французский, итальянский, английский, арабский, португальский, испанский, болгарский, польский, чешский, словацкий, литовский, латышский и норвежский.

## Развёртывание

Контейнер использует отдельный каталог данных и порт 30810. Для интеграции задайте одинаковый секрет `INTERNAL_API_KEY` в ProntoF и в сервере Home Master. Секрет передаётся только между серверами.

Программный предел 500 GB не означает, что на TrueNAS достаточно места: проверьте свободное место под исходник, временные части и итоговый файл.
