# ProntoF

Независимая платформа видеотеки и локальной обработки видео.

## Принципы проекта

- Собственные пользователи, регистрация, роли и авторизация.
- Собственная база данных и файловое хранилище.
- Никакого импорта пользователей или данных из ProntoFix / ProntoFix1.
- Отдельный Docker-контейнер и отдельный каталог данных для тестирования на TrueNAS.
- Все изменения выполняются в этом репозитории, ветка main.

## Первая версия

- FastAPI + SQLAlchemy + JWT.
- Регистрация первого пользователя с ролью владельца; последующие регистрации — обычные пользователи.
- Chunked upload (части до 32 MiB) с отдельной сборкой файла.
- Видеотека с разграничением доступа.
- Очередь обработки с одним CPU worker.
- Faster-Whisper CPU int8, исходный текст и SRT.
- Argos Translate как локальный переводчик при наличии установленной языковой пары.
- Редактирование текста и субтитров, повторная генерация SRT.
- Docker Compose с отдельным volume.

## Быстрый запуск

См. [docs/INSTALL_TRUENAS.md](docs/INSTALL_TRUENAS.md).

## Важно

Текущая версия — тестовая основа. До публикации в интернете необходимо настроить HTTPS, резервное копирование и смену секретов. Не используйте одинаковые каталоги данных с другими приложениями.
