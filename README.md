# ProntoF

Независимая платформа видеотеки и локальной обработки видео.

## Принципы проекта

- Собственные пользователи, регистрация, роли и авторизация.
- Собственная база данных и файловое хранилище.
- Никакого импорта пользователей или данных из ProntoFix / ProntoFix1.
- Отдельный Docker-контейнер и отдельный каталог данных для тестирования на TrueNAS.
- Все изменения выполняются в этом репозитории, ветка main.

## Что уже заложено в первой версии

- FastAPI + SQLAlchemy + JWT.
- Автоматическое создание первого владельца: логин `owner`, пароль задаётся через `OWNER_PASSWORD`.
- Самостоятельная регистрация обычных пользователей.
- Хранение паролей через Argon2.
- Видеотека с приватным доступом по умолчанию и возможностью включить общий доступ владельцем видео.
- Chunked upload: части до 32 MiB, программный лимит до 500 GB, проверка свободного места перед записью очередной части.
- Видеопросмотр через короткоживущий playback token, без загрузки всего видео в память браузера.
- Очередь обработки с одним CPU worker.
- Faster-Whisper CPU int8, исходный текст и временные метки.
- Argos Translate при наличии установленной языковой пары; отсутствие пакета явно отображается в статусе задачи.
- Редактирование распознанного и переведённого текста с обновлением данных субтитров.
- Docker Compose, отдельный volume и отдельный тестовый порт 30810.
- GitHub Actions: синтаксическая проверка Python и JavaScript.

## Первый запуск

1. Скопируйте `.env.example` в `.env`.
2. Задайте уникальные `SECRET_KEY` и `OWNER_PASSWORD`.
3. Соберите и запустите `docker compose up -d --build`.
4. Войдите как `owner` с паролем из `.env`.
5. Создайте обычные учётные записи через регистрацию.

Подробная инструкция: [docs/INSTALL_TRUENAS.md](docs/INSTALL_TRUENAS.md).

## API

После запуска доступны:
- `/docs` — Swagger API.
- `/api/health` — состояние сервера и поддерживаемые языки.
- `/api/auth/register`, `/api/auth/login`, `/api/auth/me`.
- `/api/videos` — видеотека.
- `/api/jobs` — очередь обработки.

## Текущие ограничения тестовой версии

- Это начальная рабочая основа, а не готовый production-релиз.
- Перед публичным доступом нужны HTTPS, резервное копирование, ограничение частоты запросов и проверка безопасности.
- Перевод доступен только для реально установленных языковых пар Argos Translate. Пакетный менеджер языковых моделей будет следующим этапом.
- Субтитры пока экспортируются в SRT; выбор дорожки в плеере и встроенный редактор по таймкодам предстоит расширить.
- Обработка выполняется на CPU последовательно. Длительные видео могут обрабатываться много часов.
- Значение 500 GB — программный верхний предел, а не гарантия, что NAS располагает таким объёмом. Для работы требуются место под оригинал, временные данные и результаты.
- GitHub Actions проверяет синтаксис; функциональные интеграционные тесты и реальный запуск контейнера на TrueNAS ещё предстоят.

## Безопасность данных

Не подключайте каталоги данных других приложений. Не удаляйте каталог `data` при обновлении контейнера. Не публикуйте файл `.env`.
