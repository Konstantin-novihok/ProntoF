# ProntoF — Home Master с локальной обработкой видео

**Единственный рабочий репозиторий: Konstantin-novihok/ProntoF, ветка main.**

ProntoF содержит пользовательское приложение Home Master и внутренний CPU-сервис обработки видео в одном репозитории и одном наборе CI/CD. Отдельного пользовательского приложения ProntoF, второго входа и отдельной пользовательской видеотеки нет.

## Архитектура

- **Home Master** — единственное пользовательское приложение: дизайн, навигация, авторизация, роли, клиенты, заказы, файлы и Android APK.
- **Видеобработка ProntoF** — внутренний сервис в Docker-сети. Он не публикует порт наружу, не имеет пользовательского интерфейса и не используется для самостоятельной регистрации.
- Видео загружается из формы конкретного заказа Home Master. Состояние обработки и результаты связаны с этим заказом.
- Общая библиотека файлов остаётся в Home Master. Управлять файлами библиотеки может только суперпользователь.
- Внутренний API защищён общим секретом `INTERNAL_API_KEY`, который хранится только в локальном `.env`, не в GitHub.

## Большие видео

- Программный предел одного файла — до 500 GB.
- Загрузка идёт частями; целый файл не помещается в оперативную память.
- Числовой лимит не показывается в пользовательском интерфейсе.
- 500 GB — программный предел, а не гарантия свободного места. Для исходника и временных файлов требуется достаточное место на диске.
- Обработка выполняется на CPU. На маломощном сервере она может занимать длительное время.

## Структура

- `home-master/server/` — сервер Home Master, скопированный из проверенного проекта.
- `home-master/web/` — оригинальный интерфейс Home Master.
- `android/` — Android-оболочка Home Master.
- `server/app.py` — внутренний ProntoF worker/API.
- `docker-compose.yml` — оба сервиса в одной сети, worker без опубликованного порта.

## Локальный запуск

1. Скопируйте `.env.example` в `.env`.
2. Задайте уникальные пароли и случайные секреты. Не публикуйте `.env`.
3. Укажите реальные пути к двум каталогам данных.
4. Запустите:

```bash
docker compose up -d --build
```

Home Master будет доступен на порту `HOME_MASTER_PORT` (по умолчанию 30802). Worker доступен только внутри Docker-сети по имени `prontof-worker:8000`.

## APK

GitHub Actions собирает один APK Home Master из каталога `android/`. Отдельный APK ProntoF не выпускается.
